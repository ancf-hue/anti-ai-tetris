# 🧩 Анти ИИ Тетрис / Anti AI Tetris

Социальный бесплатный игровой проект, бросающий вызов предсказуемости и строгим алгоритмам. Пока мир пытается все просчитать с помощью нейросетей, **Анти ИИ Тетрис** возвращает в игру чистый человеческий азарт и здоровый пространственный хаос.

Игра разработана на чистом HTML5/CSS3/JavaScript без использования тяжелых внешних 3D или физических движков (Three.js, Cannon.js и др.). Проект полностью автономен, оптимизирован под мобильный формат 9:16 и запускается на любом устройстве без интернета.

---

## 🌪️ Главная фишка: Управляемый Хаос

* Фигуры смещаются вниз по классической ровной траектории, но непрерывно и хаотично вращаются в 3D-пространстве по всем трем осям.
* До самого момента приземления игрок не знает, какой именно гранью и стороной блок коснется стопки — это ломает любые алгоритмы предсказания ИИ.
* **Ортогональное выравнивание (Snap-to-Grid):** В момент касания физика хаоса отключается, углы фигуры мгновенно округляются до ровных 90 градусов, а сама деталь четко встает в пазы классической сетки Тетриса, формируя аккуратную стопку.

---

## 🛠️ Технологический стек

* **Движок:** Написан с нуля (Vanilla JS, ES6+).
* **Графика:** Нативный HTML5 Canvas (3D-рендеринг, матрицы поворота и перспектива написаны вручную, без библиотек).
* **Звук:** Web Audio API (звуковые эффекты шага, фиксации и сгорания линий генерируются кодом на лету с помощью встроенных осцилляторов, никаких внешних `.mp3` файлов).
* **Анимация:** Попиксельное покадровое сглаживание на основе `requestAnimationFrame` и Delta Time (стабильная скорость падения без лагов на экранах 60Гц и 120Гц).
* **Стилизация:** Адаптивный CSS под мобильный формат 9:16 со встроенным Base64 `favicon.ico` логотипом.

---

## 🚀 Как запустить локально

Так как проект не имеет внешних зависимостей и не делает запросов к внешним CDN, вам не нужен локальный сервер:
1. Скачайте репозиторий или скопируйте файл `index.html`.
2. Дважды кликните по файлу `index.html` в любом браузере (Chrome, Safari, Firefox, Edge).
3. Нажмите кнопку **СТАРТ** и играйте!
